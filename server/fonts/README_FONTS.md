# Bundled Pixel Fonts

These fonts are bundled for e-ink/pixel-style rendering.

## Sources

- zpix.ttf
  - GitHub: https://github.com/SolidZORO/zpix-pixel-font
  - Release: https://github.com/SolidZORO/zpix-pixel-font/releases
  - Supports Chinese pixel-style rendering.

- ark-pixel-*.ttf
  - GitHub: https://github.com/TakWolf/ark-pixel-font
  - Release: https://github.com/TakWolf/ark-pixel-font/releases
  - Bundled variants include zh_cn / zh_hk / zh_tw / ja / ko / latin.

- fusion-pixel-*.ttf
  - GitHub: https://github.com/TakWolf/fusion-pixel-font
  - Release: https://github.com/TakWolf/fusion-pixel-font/releases
  - Bundled variants include zh_hans / zh_hant / ja / ko / latin.

## Recommended Chinese fonts

For Simplified Chinese:

- zpix.ttf
- fusion-pixel-12px-proportional-zh_hans.ttf
- fusion-pixel-12px-monospaced-zh_hans.ttf
- ark-pixel-12px-proportional-zh_cn.ttf

For Traditional Chinese:

- fusion-pixel-12px-proportional-zh_hant.ttf
- fusion-pixel-12px-monospaced-zh_hant.ttf
- ark-pixel-12px-proportional-zh_tw.ttf
- ark-pixel-12px-proportional-zh_hk.ttf

The app's font picker opens this `fonts/` folder by default.
